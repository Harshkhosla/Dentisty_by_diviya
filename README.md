# Dentistry by Divya

React website for Sadhnani's Dental Care (Jaipur), built with Vite, React Router and Tailwind CSS v4.

## Getting started

```bash
npm install
npm run dev      # start dev server
npm run build    # production build into dist/
npm run preview  # serve the production build
```

## Structure

- `src/pages/` — Home, About, Services, Contact
- `src/components/` — Header, Footer, shared UI
- `src/data.js` — clinic details, services and testimonials (edit copy here)
- `src/assets/` — images
